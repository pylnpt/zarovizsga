2. tétel — Magasszintű prog. I · Adatszerkezetek és algoritmusok

a) Magasszintű programozási nyelvek I

Hivatalos kérdés: 1. Tömbök és listák 2. Rekordok, class és struct 3. Felsorolásos típusok 4. Metódusok 5. Paraméterátadás módjai, változó paraméterszám 6. Programozási nyelvek fordítási és futtatási megoldásai 7. .NET keretrendszer felépítése, más programozási nyelvek és keretrendszerek

Tömbök és listák

Tömb és lista összetett adattípusok — elemeket tartalmaznak. - Homogén: minden elem azonos típusú - Véletlen elérésű: bármely elem közvetlenül elérhető konstans időben - Folytonos: elemek folytonos memóriaterületen tárolódnak

Tömb: fix méret, deklaráláskor megadott méret. C#-ban: int[] arr = new int[10];

Lista (List<T>): dinamikus méretű — automatikus bővítés. Implementáció gyakran háttér-tömb, amit szükség esetén nagyobbra másolnak.

Rekordok, class, struct

Rekord: összetett, heterogén adattípus — különböző típusú mezőkkel. A mezőknek saját nevük van.

C#-ban két forma: - class — referenciatípus, heap-en, GC kezeli, null lehet - struct — értéktípus, stack-en, érték szerint másolódik, nem lehet null

class struct
Memória heap stack
Másolás referencia érték szerint
Default érték null minden mező default
Öröklődés igen nem (csak interface)

Felsorolásos típusok (enum)

Megnevezett konstansok halmaza. C#-ban: enum Szin { Piros, Kek, Zold }. Alapértelmezetten int-re fordul, de explicit megadhatjuk az alaptípust.

Metódusok

Függvény, ami egy osztályhoz vagy struktúrához kötődik. Szignatúra: név + paraméter típusok. Lehet: - Static: osztályhoz kötött, nem példányhoz - Példányszintű: az adott objektumon hívható

Túlterhelés (overload): azonos név, más paramétertípus.

Paraméterátadás módjai

  • Érték szerinti (by value): alapeset — másolat kerül át
  • Referencia szerinti (ref): a paraméter referenciaként megy, a metódusban módosítható; be- és kimenet is
  • Kimeneti (out): a metódusnak kötelezően értéket kell adnia neki; bemenetnek nem kell inicializálva lennie
  • in: csak olvasható referencia
  • params (változó paraméterszám): void Print(params int[] nums) — több argumentumot fogad el, tömbként kapja meg

Programozási nyelvek fordítási és futtatási megoldásai

Fordítási típusok: - Compiled (AOT — Ahead-of-Time): forráskód → gépi kód már a fordításkor. Pl. C, C++, Rust. Gyors futás, hosszú build. - Interpreted: futásidőben értelmezi (pl. Bash, eredeti Python). Lassú, de rugalmas. - JIT (Just-in-Time): közbenső kód, ami futásidőben fordul gépi kódra. Pl. Java (JVM), .NET (CLR), modern JS (V8). Kombinálja a kettőt.

.NET keretrendszer

A .NET egy fejlesztési és futtatási környezet.

Fő összetevők: - CLR (Common Language Runtime): futtatási környezet — JIT, GC, type system - BCL (Base Class Library): alaposztálykönyvtár (kollekciók, IO, hálózat) - FCL (Framework Class Library): kibővített könyvtár (Web, GUI) - IL (Intermediate Language) / MSIL: közbenső, platformfüggetlen kód, amire minden .NET nyelv (C#, F#, VB.NET) fordul

Lépések: 1. Forráskód (C# stb.) → IL/MSIL kód 2. JIT futásidőben → natív gépi kód 3. CLR menedzseli a memóriát (GC), típusbiztonságot, kivételeket

Más nyelvek és keretrendszerek

  • JVM (Java Virtual Machine): Java, Scala, Kotlin, Groovy fut rajta. Bytecode + JIT.
  • Python: interpreter (CPython) — bytecode-ra fordul, és VM értelmezi. PyPy: JIT-tel.
  • Node.js: JavaScript V8 motorral, JIT.
  • Go: AOT, saját runtime, goroutine-ok.
  • Rust: AOT, memóriabiztos, GC nélkül (ownership).

Algoritmus fogalma és tulajdonságai

Algoritmus: véges sok, jól definiált lépés sorozata, amely véges idő alatt megoldja a feladatot.

Tulajdonságai: - Véges: véges lépés után befejeződik - Determinisztikus / egyértelmű: minden lépés pontosan értelmezhető - Általános: több bemenetre megoldja - Hatékony: elfogadható erőforrás-fogyasztás

Megadási módjai, eszközei

  • Szöveges leírás: természetes nyelven
  • Pszeudokód: kvázi-programkód, nyelvfüggetlen
  • Folyamatábra: grafikus (téglalap = művelet, rombusz = döntés)
  • Struktogram (Nassi-Shneiderman): egymásba ágyazott blokkok
  • Jackson-diagram: strukturált tervezéshez

Strukturált algoritmus szerkezete

Három alapszerkezet: 1. Szekvencia — lépések egymás után 2. Szelekció — feltételes (if / else, switch / case) 3. Iteráció — ciklus (while, for, do-while)

A strukturált algoritmusban goto/jump nincs — csak ez a 3 vezérlési szerkezet.

Programozási tételek

1. Sorozathoz elemi értéket rendelők (egyetlen választ adnak): - Eldöntés: van-e a sorozatban olyan elem, ami megfelel a feltételnek? (igaz/hamis) - Kiválasztás: mi az első ilyen elem indexe? (feltételezi, hogy van) - Lineáris keresés: ha van, hol? Ha nincs, jelezzük. - Megszámlálás: hány ilyen elem van? - Maximum-keresés: mi a legnagyobb elem? - Összegzés: mi az elemek összege/szorzata?

2. Sorozathoz sorozatot rendelők: - Másolás: új sorozat, transzformációval (pl. minden elem négyzete) - Kiválogatás: új sorozat csak a feltételnek megfelelő elemekkel - Szétválogatás: két új sorozat (megfelel / nem felel meg) - Metszet (közös rész) — két sorozat közös elemei

3. Több sorozathoz egy sorozatot rendelők: - Unió: két rendezett sorozatból új rendezett - Metszet: rendezett sorozatok közös elemei - Összefuttatás (merge): rendezett sorozatok rendezett egyesítése

Rendező algoritmusok és hatékonyságuk

Algoritmus Idő (átlag) Idő (legrosszabb) Memória Stabil?
Buborék rendezés O(n²) O(n²) O(1) igen
Beszúrásos O(n²) O(n²) O(1) igen
Kiválasztásos O(n²) O(n²) O(1) nem
Gyorsrendezés (Quicksort) O(n log n) O(n²) O(log n) nem
Összefésüléses (Mergesort) O(n log n) O(n log n) O(n) igen
Kupacrendezés (Heapsort) O(n log n) O(n log n) O(1) nem

Buborék: szomszédos elemeket cserélgetünk, ha rossz a sorrend. n-1 menet. Beszúrásos: elem behelyezése a rendezett bal részbe. Kiválasztásos: legkisebb keresés, csere az aktuális pozícióba. Quicksort: osztó-uralkodó, pivot körül szétválogat, rekurzív. Mergesort: kettébontás, rekurzív rendezés, összefuttatás. Heapsort: maxhalom építés, gyökér ismételt kivétele.

Visszalépéses keresés (backtracking)

Algoritmus-séma: rekurzív próbálkozás. Több opció közül választunk, ha zsákutca → visszalépés. Tipikus feladatok: N királynő, sudoku, gráfszínezés, Hamilton-út.

Lépések: 1. Aktuális állapotban próbálunk minden lehetséges választást 2. Ha jó → tovább rekurzívan 3. Ha végállapot → siker 4. Ha nem jó / zsákutca → vissza az előzőhöz, másik opciót

Halmaz adatszerkezet különböző konstrukciói

A halmaz tartalmaz elemeket rendezetlenül, ismétlés nélkül. Műveletek: hozzáadás, törlés, elem-e?, unió, metszet.

Konstrukciók:

  1. Rendezetlen sorozatos (lista alapú): elemek tömb/lista végére. Egyszerű, de minden művelet O(n).

  2. Rendezett sorozatos (rendezett tömb): elemek sorrendben tárolva. Bináris keresés O(log n)-ben dönti el a tartalmazást. Beszúrás/törlés O(n) az eltolás miatt.

  3. Karakterisztikus függvény (bit-vektor): ha az univerzum véges (pl. {0…1000}), egy bit-tömb minden indexhez 0/1-et tárol. Minden művelet O(1), de csak véges, kis univerzumra.

  4. Hash-tábla (lásd 3.b tétel): átlag O(1) műveletek.

  5. Fa (kiegyensúlyozott bináris keresőfa, pl. AVL, piros-fekete): O(log n) műveletek + rendezett bejárás.
