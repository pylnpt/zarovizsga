4. tétel — Magasszintű prog. I (típusok) · Operációs rendszerek

a) Magasszintű programozási nyelvek I — alapok

Hivatalos kérdés: 1. Alaptípusok, változók, konstansok, literálok 2. Operátorok 3. Szelekciós vezérlési szerkezetek 4. Ciklusok 5. Érték- és referenciatípusok memóriamenedzsmentje, stack és heap 6. Változók hatásköre és élettartama 7. Programozási nyelvek generációi, imperatív, funkcionális és deklaratív nyelvek

Alaptípusok

Primitív típusok C#-ban: - Egész: byte (8), short (16), int (32), long (64), előjeles és előjel nélküli (uint, ulong stb.) - Lebegőpontos: float (32), double (64), decimal (128, precíz pénzügyi) - Logikai: bool (true/false) - Karakter: char (Unicode, 16 bit) - Szöveg: string (referenciatípus, de érték-szemantikás, immutable)

Változók, konstansok, literálok

  • Változó: memóriaterület + név + típus; értéke változhat. int x = 5;
  • Konstans: értéke a fordításkor rögzül, futás közben nem változhat. const double PI = 3.14;
  • Read-only (readonly): csak konstruktorban kaphat értéket, utána nem (C# specifikus)
  • Literál: közvetlen, beégetett érték: 5, 3.14, "szöveg", true, 'a'

Operátorok

  • Aritmetikai: +, -, *, /, % (maradékos osztás), ++, --
  • Összehasonlító: ==, !=, <, >, <=, >=
  • Logikai: &&, ||, ! (rövidzár)
  • Bitenkénti: &, |, ^ (XOR), ~ (NOT), <<, >>
  • Értékadó: =, +=, -=, *=, /= stb.
  • Ternáris: feltétel ? a : b
  • Null-coalescing (C#): a ?? b — ha a null, akkor b

Operátor precedencia: szorzás osztás > összeadás kivonás > összehasonlító > logikai. Zárójellel felülírható.

Szelekciós vezérlési szerkezetek

if:

if (feltétel) { ... }
else if (másik) { ... }
else { ... }

switch:

switch (érték) {
    case 1: ...; break;
    case 2: ...; break;
    default: ...; break;
}

Modern C#-ban pattern matching: switch expression, is operátor.

Ciklusok

  • while: elöltesztelő — while (feltétel) { ... }
  • do-while: hátultesztelő — legalább egyszer lefut
  • for: számláló — for (i=0; i<n; i++) { ... }
  • foreach: kollekció elemein — foreach (var item in coll) { ... }. Az IEnumerable interfészen működik.

Ciklusvezérlés: break (kilép), continue (ugrik a következő iterációra), return.

Érték- és referenciatípusok memóriamenedzsmentje

Értéktípus (struct, int, double, bool, char, enum): - A stack-en él (lokális változóknál) - Másoláskor érték szerint - Élettartama a hatókörhöz kötve - Nincs null (kivéve Nullable<T>/?)

Referenciatípus (class, string, array, delegate): - Az objektum a heap-en él - A változó csak egy referencia rá (stack-en) - Másoláskor a referenciát másoljuk - GC (Garbage Collector) szabadítja fel, amikor nincs rá hivatkozás

Stack és heap

Stack: gyors, LIFO. Funkcióhívások keretadatai, lokális értéktípusú változók. Méret korlátozott (stack overflow). Automatikus felszabadítás.

Heap: lassabb, dinamikus allokáció. Referenciatípusú objektumok. GC kezeli (.NET-ben generációs GC).

Boxing / unboxing: értéktípus → object/interface (heap-re kerül), és vissza. Lassú, kerülendő.

Változók hatásköre és élettartama

Hatáskör (scope): hol látható a változó. - Block: { } blokkban - Metódus: a metóduson belül - Osztály: mezők az egész osztályban - Namespace / project

Élettartam (lifetime): mikor él a változó a memóriában. - Lokális: a blokkból kilépve megszűnik (stack) - Mező: az objektum élettartamáig (heap) - static: az AppDomain élete

Programozási nyelvek generációi

  1. 1GL: gépi kód — bináris, közvetlenül a CPU-nak (nullák és egyesek)
  2. 2GL: assembly — mnemónikus szimbólumok, 1:1 a gépi kóddal
  3. 3GL: magas szintű, hardverfüggetlen (C, Pascal, Fortran, C#, Java)
  4. 4GL: problématerület-specifikus, gyakran deklaratív (SQL, MATLAB, Visual Basic, üzleti DSL-ek)
  5. 5GL: mesterséges intelligencia, logikai programozás (Prolog)

Imperatív, funkcionális és deklaratív nyelvek

Imperatív: "hogyan" — lépéssorozat. Állapotot változtatunk. Pl. C, C#, Java, Python.

Funkcionális: függvények kompozíciója, immutable adat, side-effect kerülése. Pl. Haskell, Lisp, F#, Erlang. C#-ban LINQ + lambda.

Deklaratív: "mit" akarunk, nem "hogyan". Pl. SQL ("SELECT * WHERE …"), HTML, Prolog.

Objektum-orientált: osztályok, példányok, öröklődés, polimorfizmus. Pl. C++, C#, Java.

Logikai programozás: szabályok és tények, az interpreter következtet. Pl. Prolog.

OS fogalmak, kernel

Operációs rendszer: a hardver és az alkalmazások közötti réteg. Erőforrás-menedzser (CPU, memória, IO, fájlok), és API-t nyújt a programoknak.

Kernel: az OS magja, közvetlenül a hardverrel beszél. Privilegizált módban fut. - Monolitikus kernel: minden szolgáltatás a kernelben (Linux). Gyors, de nagy. - Mikrokernel: csak a minimum a kernelben, a többi user-space szervízben (Minix, QNX). Stabilabb, lassabb. - Hibrid: kettő keveréke (Windows NT, macOS).

Processz (folyamat): futó program egy példánya. Saját memóriatérrel, állapottal, fájlleíróval.

Szál (thread): egy processzen belüli könnyűsúlyú végrehajtási egység, közös memóriát használnak.

Felhasználói vs kernel mód: felhasználói módban korlátozott jogok, kernel módban teljes hozzáférés.

Virtualizáció

Cél: egy fizikai gépen több, egymástól izolált környezet.

  • Teljes virtualizáció (full): VM-ek külön OS-szel — VMware, VirtualBox, Hyper-V. Hypervisor kezeli (Type 1: bare-metal, Type 2: hostolt).
  • Para-virtualizáció: vendég OS tud arról, hogy virtuális.
  • Konténerek (Docker, LXC): OS-szintű izoláció, közös kernel — gyors, könnyű.

Fájl- és könyvtárkezelés

Fájl: logikai adategység névvel, attribútumokkal (méret, jogosultság, dátum).

Könyvtár (directory): fájlok hierarchikus szervezése; fa-struktúra.

Fájlrendszerek: - NTFS (Windows): journaling, ACL-ek, nagy fájlok támogatása - FAT32 / exFAT: egyszerű, kompatibilis, USB - ext4 (Linux): journaling, gyors - APFS (macOS): SSD-optimalizált, snapshot-ok - ZFS, Btrfs: modern, snapshot, RAID-szerű képességek

Diszk kezelés, RAID

Partícionálás: lemez logikai részekre. MBR (régi, max 2TB) vs GPT (modern, nagy lemezekhez).

RAID (Redundant Array of Independent Disks): - RAID 0 (striping): sebesség, nincs redundancia (egy lemez hibája → adatvesztés) - RAID 1 (mirroring): tükrözés, redundancia, sebesség olvasásra jó - RAID 5: striping + 1 paritás — 1 lemez hibáját tűri - RAID 6: striping + 2 paritás — 2 lemez hibáját tűri - RAID 10: mirror + stripe — gyors és redundáns

Átirányítások és szűrők

Standard streamek: stdin (0), stdout (1), stderr (2).

Átirányítás (shell): - cmd > file — stdout fájlba - cmd >> file — hozzáfűz - cmd 2> file — stderr fájlba - cmd < file — stdin fájlból - cmd1 | cmd2 — pipeline, cmd1 stdout-ja cmd2 stdin-je

Szűrők (filter): input-feldolgozó kis programok, jellemzően sorokkal: - grep: minta-keresés - sed: keresés-csere - awk: oszlop-feldolgozás - sort, uniq, wc, head, tail, cut

Jogosultsági rendszerek

Unix/Linux (octal mode): - 3 csoport: owner, group, others - 3 művelet: r (read, 4), w (write, 2), x (execute, 1) - Pl. 755 = rwxr-xr-x; chmod 644 file = csak az owner ír - chown (tulajdonos), chgrp (csoport)

Windows ACL: részletesebb, felhasználónként és csoportonként, örökölhető szabályok. Allow / Deny szabályok.

Azonosságok: mindkettő autentikáció + autorizáció. Különbség: Linux egyszerűbb (3×3 bit), Windows finomabban szabályozható (ACL).

Processz kezelés

Processz állapotai: new → ready → running → waiting (IO-ra) → terminated.

Ütemező (scheduler): dönt, melyik processz fut. Algoritmusok: - FCFS (First Come First Served) - SJF (Shortest Job First) - Round Robin (időszelet) - Prioritás-alapú - Multilevel queue / feedback

Műveletek: - Fork: új processz létrehozása (Unix) - Exec: processz tartalmának cseréje másik programmal - Wait: szülő várja a gyerek befejezését - Kill: processz megszüntetése (szignállal)

Szignálok és kezelésük

Szignál (signal): aszinkron értesítés a processznek.

Tipikus szignálok (Unix): - SIGTERM (15): kérés a leállásra (graceful) - SIGKILL (9): azonnali leállítás, nem fogható el - SIGINT (2): Ctrl+C - SIGHUP (1): terminál bezárás - SIGSEGV: memóriasértés - SIGCHLD: gyerek befejeződött

Kezelés: a processz handlert regisztrálhat (signal() vagy sigaction()). A SIGKILL és SIGSTOP nem fogható el.

Adatmentés és archiválás

Backup típusok: - Teljes (full): minden adat - Inkrementális: csak az utolsó backup óta változott - Differenciális: az utolsó teljes óta változott

3-2-1 szabály: 3 másolat, 2 különböző médián, 1 off-site.

Eszközök: tar, rsync, dd, cron (időzítés), borg, restic (deduplikálós, titkosított).

Archiválás: hosszú távú megőrzés (gyakran tömörítéssel) — tar.gz, zip, 7z.

Shell-scriptek

Shell-script: parancssori parancsok sorozata egy fájlban — automatizálásra.

Tipikus elemek: - #!/bin/bash — shebang (a shell megjelölése) - Változók: VAR=érték, hivatkozás $VAR - Vezérlés: if, for, while, case - Funkciók: function név() { … } - Argumentumok: $1, $2, $@, $# - Exit kód: $?

Példa:

#!/bin/bash
for f in *.log; do
    gzip "$f"
done
